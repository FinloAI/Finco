# Finco

**Finco is a simple, natural, AI-friendly, and Python-compatible programming language.**

Finco is designed to make programming easier to read, easier to learn, and more natural to write without giving up the power of the Python ecosystem. It combines familiar programming concepts with clearer language structures, integrated artificial intelligence tools, mathematical expression support, application development features, and optional high-performance execution.

The project began with a simple idea: programming languages should help people express their thoughts instead of forcing them to constantly translate those thoughts into rigid syntax. Code should remain precise enough for computers while becoming more understandable to humans.

Finco is currently at version **1.0.0**, with the official build identifier `20260722-V1-F0100`. 

## Philosophy

Finco is built around clarity, accessibility, compatibility, and creativity.

Many programming languages are powerful, but their syntax can create unnecessary barriers for beginners. Small punctuation mistakes, unfamiliar structures, and complicated library interfaces can distract people from the problem they are trying to solve. Finco reduces these barriers by offering readable language forms, intelligent correction tools, and consistent interfaces for common tasks.

However, simplicity does not mean removing advanced capabilities. Finco is intended to support both learners and experienced developers. A beginner can use it to understand loops, functions, data, mathematics, and machine learning, while a more advanced user can work with Python libraries, PyTorch objects, parallel execution, native acceleration, and lower-level model training controls.

Finco does not aim to replace Python. Instead, it acts as a more natural and organized layer above Python. Existing Python knowledge remains useful, and much of the Python ecosystem can continue to be used. This allows Finco to introduce a different programming experience without isolating developers from established tools and libraries.

## What Finco Does

Finco is a general-purpose programming language with a strong focus on artificial intelligence, mathematics, education, data processing, and rapid application development.

At its core, Finco provides familiar programming features such as variables, expressions, collections, functions, conditions, loops, exceptions, modules, and project organization. It keeps Python-compatible behavior where possible while introducing alternative forms that are designed to be easier to understand.

Finco also includes an intelligent correction system. It can recognize certain spelling mistakes, full-width punctuation, mixed brackets, missing separators, parameter aliases, and other deterministic issues. The correction system is intentionally cautious: it should repair a program only when the intended meaning is sufficiently clear. When a change could alter the meaning of the program, Finco should ask rather than silently guess.

Artificial intelligence is one of the central areas of the language. The official Finlai library provides a unified environment for data loading, model construction, training, validation, evaluation, persistence, and inference. It is intended to make classical machine learning, neural networks, deep learning, reinforcement learning, and self-play more approachable through a consistent interface.

Finlai covers traditional algorithms such as regression, decision trees, random forests, support vector machines, nearest-neighbor methods, clustering, and dimensionality reduction. It also supports neural architectures including multilayer perceptrons, convolutional networks, recurrent networks, attention systems, Transformers, mixture-of-experts models, diffusion models, Ladder Networks, and state-space models. Developers can use high-level training tools or access lower-level operations when they need more control.

Mathematics is another important part of Finco. The language is designed to understand common mathematical symbols, sets, quantifiers, ranges, and expressions more directly than ordinary source code usually allows. The Fimath module extends this idea with configurable numerical behavior and exact scalar computation while keeping traditional Python-style numerical semantics available.

Finco also includes tools beyond command-line programming. FinApp is intended for building modern desktop applications and provides the foundation for Finco Studio. FPlot offers a unified way to create common data visualizations. Fipen provides a creative drawing environment based on the moving-pen concept while extending it with retained canvases, layers, batching, and animation.

For computationally intensive work, Finco provides optional native acceleration through FastCore. Supported numerical sections can be compiled through a controlled C++17 boundary, while unsupported operations can continue to run through Python. This hybrid approach allows Finco to improve performance without requiring every program to be rewritten in a lower-level language.

The language also includes project tools for formatting, testing, diagnostics, interactive use, Jupyter integration, editor support, and safer execution. These tools are meant to make Finco a complete development environment rather than only a syntax experiment.

## AI-Friendly by Design

Finco is described as AI-friendly for two reasons.

First, it is designed for people who want to study, create, and experiment with artificial intelligence. Machine-learning concepts are treated as a central part of the language ecosystem rather than as an unrelated collection of external packages.

Second, Finco aims to be understandable to AI-assisted development systems. Clear structures, predictable behavior, cautious automatic correction, and consistent interfaces can make programs easier for both humans and AI systems to analyze, generate, explain, and improve.

This does not mean allowing an AI system to change programs without control. Finco emphasizes transparent behavior. Corrections, automatic imports, optimizations, and backend choices should be visible and explainable. The developer should remain in control of what the program does.

## Who Finco Is For

Finco is intended for students learning programming, researchers exploring new AI ideas, developers building experimental models, educators teaching computer science, and creators who want to turn ideas into working software with less syntactic friction.

It may be especially useful for people who like Python but want more readable forms, more integrated AI tools, stronger mathematical notation, and a more unified development experience.

## Project Direction

Finco 1.0.0 establishes the first complete public foundation of the language. Future development will continue to improve the compiler, runtime, documentation, editor integration, application framework, mathematical tools, artificial intelligence backends, package ecosystem, and cross-platform experience.

Finco is still evolving. Some features may change as the language becomes more consistent, reliable, and practical. The current release should therefore be viewed both as a usable programming environment and as the beginning of a larger language-design project.

The long-term goal of Finco is to create a programming language in which advanced computing feels less distant: a language that remains precise, capable, and compatible, while allowing people to focus more clearly on ideas, models, problems, and creation.
